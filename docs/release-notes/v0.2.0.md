## 새 기능

### 이전·다음 묵상 이동 — 하루 하나 제한 해제 (F-4)
- "다 봤어요"를 누르면 메인으로 돌아가고, 그 줄이 바로 다음 묵상으로 바뀐다. 같은 날 구약·신약을 여러 개 이어 읽을 수 있다
- 묵상 화면과 메인 줄에서 이전·다음 묵상으로 옮겨 가며 볼 수 있다. 이동만으로는 진행 위치가 바뀌지 않는다
- "읽음" 표시는 그날 눌렀는지가 아니라 진행 위치까지 읽었는지로 정한다
- PRD: [f-4-prev-next.md](../prd/f-4-prev-next.md) · 구현 `233fca8`

## 고친 것

### 2025 묵상에서 설교 대신 새벽예배 생방송이 나오던 문제 (F-6)
- 원인: 앱이 글 페이지에 박힌 첫 유튜브 영상을 썼는데, 2025 글에는 생방송(약 90분) 영상만 박혀 있었다
- 이제 영상은 유튜브 검색(`search.list`, 검색어는 성경 본문)으로만 찾고, 제목이 `[ 설교 | 새벽기도회 | … ]` 인 영상만 고른다. 예: 2025/09/13 잠언 24:11-22 → 설교 영상 `kH2QadelWio`(약 21분)
- 설교 영상을 못 찾으면 생방송으로 대신하지 않고 "영상 없음"을 보인다
- 2020 신약 묵상은 이전처럼 그날 영상이 나온다
- PRD: [f-6-sermon-video.md](../prd/f-6-sermon-video.md) · 구현 `04ca7ec` · PR #6

### 메인 이전·다음 이동 중 로딩 스피너 제거
- 이동할 때마다 카드에 스피너가 깜빡이던 것을 없앴다 — `1c54421` · PR #5
