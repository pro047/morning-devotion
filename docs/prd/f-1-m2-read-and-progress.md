# PRD: F-1 M2 묵상 글 읽기와 진행 위치 저장

작성일: 2026-11-20 · 상위 PRD: [f-1-next-devotion.md](f-1-next-devotion.md) · 이전 마일스톤: [f-1-m1-next-pick.md](f-1-m1-next-pick.md)

F-1 을 4개 마일스톤으로 나눈 것 중 **M2** 다. 이 문서가 이번 범위의 정본이고, F-1 PRD 는 배경으로만 읽는다.

## 1. 범위
1) M1 이 고른 묵상의 **글 주소**를 만들고, 2) 글 HTML 에서 **본문·찬송·설교문**을 뽑고, 3) 구약·신약 **진행 위치를 기기에 저장**하고 "다 봤어요"로 넘기는 로직.
화면은 범위 밖이다. 로직과 단위 테스트만 만든다.

대응하는 F-1 요구: FR-1, FR-4(유튜브 제외), FR-6, US-3 의 수용 기준 1·3·4·5, US-4(9장 4번 결정 반영).

## 2. 요구사항
- R-1: 목록 HTML 에서 각 글의 **글번호**(`no=<숫자>`)를 함께 뽑는다
  - 실측(2026-11-20): `cast-search-proverbs-23.html` 의 2025/09/11(목) 잠언 23:24-35 → `no=15155`
  - 목록 링크는 `onclick="SLB('/home/board.php?...&command=body&no=15155&body_only=y&button_view=n', ...)"` 안에 있다
- R-2: 글번호로 글 주소를 만든다: `https://100church.org/home/board.php?board=cast&config=6&category=6&command=body&no=<글번호>&body_only=y&button_view=n`
- R-3: 글 주소를 받아 HTML 을 가져오는 부분은 **프로토콜 뒤에 둔다.** 테스트는 가짜 구현으로 fixture 를 돌려준다 — 테스트는 네트워크를 쓰지 않는다
- R-4 (FR-4): 글 HTML 에서 아래를 뽑는다
  - 제목: `<TITLE>` 의 글자. M1 의 제목 파서로 날짜·본문을 얻는다
  - 본문 줄: `<span ...>본문</span> 잠언 23:24-35` → `잠언 23:24-35`
  - 찬송 줄: `<span ...>찬송가</span> 454장 ‘주와 같이 되기를’` → `454장 ‘주와 같이 되기를’`
  - 설교문: 찬송 줄 다음부터 `margin:60px` div 가 닫힐 때까지. `<br />`·`<br>` 는 줄바꿈, 나머지 태그는 지우고 글자만 남긴다. HTML 엔티티는 M1 과 같이 푼다
  - 굵은 글씨(소제목·성경 구절)를 구분할지는 M4(화면)에서 정한다. M2 는 글자만 남긴다
- R-5 (FR-1, US-4): 진행 위치(구약·신약 각각 마지막으로 본 날짜)를 기기에 저장한다. 앱을 다시 실행해도 유지된다
  - 저장 방식은 설계 단계에서 정한다. 저장소는 주입할 수 있어야 한다 (테스트용 저장소로 바꿔 끼울 수 있게)
  - **저장된 값이 없을 때만** 기본값을 넣는다: 구약 2025/09/10, 신약 2020/07/11 (2026-11-20 진성 결정, F-1 PRD 9장 4번. 값은 [00-project.md](00-project.md) 3장 표)
  - 저장된 값이 있으면 기본값으로 덮어쓰지 않는다
- R-6 (FR-6): "다 봤어요" = 해당 구분의 마지막으로 본 날짜를 화면의 묵상 날짜로 바꾸고 저장한다. 다른 구분은 바꾸지 않는다

## 3. 완료 조건
아래가 전부 단위 테스트로 있고, `.sap/config` 의 `TEST_CMDS` 가 exit 0 이다.
1. `cast-search-proverbs-23.html` 에서 2025/09/11(목) 잠언 23:24-35 의 글번호가 15155, `cast-search-john-5.html` 에서 2020/07/13(월) 요한복음 5:30-47 의 글번호가 11480
2. 글번호 15155 → R-2 의 주소 문자열과 글자 하나까지 같다
3. `cast-body-15155.html` → 본문 `잠언 23:24-35`, 찬송 `454장 ‘주와 같이 되기를’`, 설교문이 `오늘 본문의 주제어는 크게 세 가지입니다.` 로 시작하고 `(작성: 김광욱)` 으로 끝난다. 설교문에 `<` 가 없다
4. `cast-body-11480.html` → 본문 `요한복음 5:30-47`, 찬송 `90장 ‘주 예수 내가 알기 전’`, 설교문이 `예루살렘 양문 곁 베데스다 못에서.` 로 시작하고 `(작성: 박성호)` 로 끝난다
5. 빈 저장소에서 진행 위치를 읽으면 구약 2025/09/10, 신약 2020/07/11 이고, 이 값과 M1 fixture 로 고른 다음 묵상이 M1 완료 조건 1·2 와 같다
6. 저장소에 구약 2025/09/11 이 이미 있으면 다시 읽어도 2025/09/11 이다 (기본값으로 덮어쓰지 않음)
7. 구약에서 2025/09/11 묵상에 "다 봤어요" → 구약 2025/09/11, 신약은 2020/07/11 그대로. 같은 저장소를 새 인스턴스로 다시 열어도 같다 (신약 쪽도 대칭으로 1건)
8. "다 봤어요"를 부르지 않고 같은 저장소를 새 인스턴스로 다시 열면 진행 위치가 그대로다
