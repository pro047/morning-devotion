# PRD: F-3 메인 화면

작성일: 2026-11-20 · 프로젝트 PRD: [00-project.md](00-project.md) · 관련: [f-1-next-devotion.md](f-1-next-devotion.md), [f-1-m4-screen.md](f-1-m4-screen.md)

## 1. 개요
지금 앱은 열자마자 지금 시간대의 묵상 화면(영상·설교문)이 나온다. 진성은 "바로 설교 본문이 보이니까 좀 당황스럽다"고 했다 (2026-11-20 M4 시뮬레이터 확인 중).
이 기능은 앱 첫 화면에 메인 화면을 둔다.
1. 메인에서 오늘 볼 오전(구약)·오후(신약) 말씀이 무엇인지 날짜와 본문 제목으로 먼저 확인한다
2. 각 말씀을 오늘 읽었는지 표시한다
3. 말씀을 누르면 그 묵상 화면으로 들어간다 — 시간과 관계없이 둘 다 열 수 있다

## 2. 목표
- 앱을 열면 설교문 대신 구약·신약 두 줄의 메인 화면이 먼저 나온다
- 메인에서 시간과 관계없이 구약·신약 묵상 어느 쪽이든 열 수 있다
- 메인에서 오늘 구약·신약 각각을 읽었는지 알 수 있다

## 3. 사용자 스토리

### US-1: 메인에서 오늘 볼 말씀 확인하기
**설명:** 진성으로서, 앱을 열면 오늘 볼 구약·신약 말씀이 무엇인지 먼저 보고 싶다. 열자마자 설교문이 나오면 당황스럽기 때문이다.
**수용 기준:**
- [ ] 앱을 열면 묵상 화면이 아니라 메인 화면이 나온다
- [ ] 2026-11-20 07:00, 빈 저장소(진행 위치 기본값)에서 메인에 구약 줄 "2025/09/11(목) 잠언 23:24-35"와 신약 줄 "2020/07/13(월) 요한복음 5:30-47"이 함께 보인다
- [ ] 00:00~11:59에는 구약 줄에, 12:00~23:59에는 신약 줄에 "지금" 표시가 있다. 다른 줄에는 없다
- [ ] 메인을 보여주는 동안에는 글 페이지·유튜브를 가져오지 않는다 (목록 검색만 한다)

### US-2: 말씀을 눌러 묵상 화면 열기
**설명:** 진성으로서, 메인에서 고른 말씀의 묵상 화면을 시간과 관계없이 열고 싶다. 점심 묵상을 놓친 날에도 볼 수 있어야 하기 때문이다.
**수용 기준:**
- [ ] 2026-11-20 07:00(오전)에 메인의 신약 줄을 누르면 "2020/07/13(월) 요한복음 5:30-47" 묵상 화면(영상·글·"다 봤어요")이 나온다
- [ ] 2026-11-20 13:00(오후)에 메인의 구약 줄을 누르면 "2025/09/11(목) 잠언 23:24-35" 묵상 화면이 나온다
- [ ] 오전에 연 신약 묵상 화면에서 "다 봤어요"를 누르면 신약 진행 위치만 바뀌고 구약은 그대로다
- [ ] "다 봤어요"를 누르면 "오늘 구약(신약) 묵상을 마쳤습니다" 화면 없이 메인으로 돌아온다 (9장 1번)
- [ ] 묵상 화면을 연 채로 시각이 12:00을 지나도 화면의 구분(구약·신약)이 다른 쪽으로 바뀌지 않는다
- [ ] 묵상 화면에서 메인으로 돌아갈 수 있다

### US-3: 오늘 읽었는지 표시하기
**설명:** 진성으로서, 메인에서 오늘 구약·신약을 각각 읽었는지 보고 싶다. 어느 쪽이 남았는지 바로 알기 위해서다.
**수용 기준:**
- [ ] 2026-11-20에 구약 "다 봤어요"를 누른 뒤 메인으로 돌아오면 구약 줄은 오늘 읽은 말씀 "2025/09/11(목) 잠언 23:24-35"와 "읽음" 표시를 보여준다. 다음 구약 말씀(2025/09/12)은 보이지 않는다
- [ ] 같은 상태에서 신약 줄은 "읽음" 표시 없이 "2020/07/13(월) 요한복음 5:30-47"을 보여준다
- [ ] 2026-11-21 00:00 이후 메인을 열면 구약 줄은 "읽음" 없이 다음 말씀 "2025/09/12(금) 잠언 24:1-10"을 보여준다
- [ ] 메인에는 읽음을 직접 체크하는 버튼이 없다. "읽음"은 묵상 화면의 "다 봤어요"로만 바뀐다

### US-4: 오늘 읽은 묵상 다시 보기
**설명:** 진성으로서, 오늘 이미 읽은 말씀을 메인에서 눌러 다시 보고 싶다.
**수용 기준:**
- [ ] 2026-11-20에 구약 "다 봤어요"를 누른 뒤 메인의 구약 줄을 누르면 "2025/09/11(목) 잠언 23:24-35" 묵상 화면(영상·글)이 다시 나온다. "오늘 구약 묵상을 마쳤습니다" 화면이 아니다
- [ ] 다시 보기 화면에는 "다 봤어요" 버튼이 없다 (9장 2번)
- [ ] 다시 보기를 해도 구약 진행 위치(2025/09/11)와 마친 날(2026-11-20)은 바뀌지 않는다

### US-5: 한쪽만 불러오지 못했을 때
**설명:** 진성으로서, 구약·신약 중 한쪽만 불러오지 못했을 때 다른 쪽은 그대로 보고 싶다.
**수용 기준:**
- [ ] 신약 목록 검색만 네트워크 오류일 때 메인의 신약 줄에 "인터넷 연결을 확인해 주세요"와 "다시 시도"가 보이고, 구약 줄은 말씀 제목을 보여주며 누를 수 있다
- [ ] 신약 줄의 "다시 시도"를 누르고 이번엔 성공하면 신약 줄에 말씀 제목이 나온다. 구약 줄은 다시 불러오지 않는다
- [ ] 한쪽 진행 위치 다음 7일 안에 글이 없으면 그 줄에 "다음 묵상을 찾지 못했습니다"가 보인다
- [ ] 위 경우 모두 진행 위치·마친 날은 바뀌지 않는다

## 4. 기능 요구사항
- FR-1: 앱을 열면 시스템은 메인 화면을 먼저 보여줘야 한다
- FR-2: 시스템은 메인에서 구약·신약 각각 한 줄을 보여줘야 한다. 줄의 말씀은 이렇게 정한다
  - 그 구분의 마친 날이 오늘(기기 로컬 날짜)이 아니면: 다음 묵상 (F-1 FR-3, M4 R-1과 같은 방법 — 진행 위치 다음 날부터 최대 7일 날짜 검색)
  - 그 구분의 마친 날이 오늘이면: 오늘 읽은 묵상(= 진행 위치 날짜의 묵상)과 "읽음" 표시
- FR-3: 시스템은 각 줄에 묵상 날짜(요일 포함)와 본문 제목을 보여줘야 한다
- FR-4: 시스템은 기기 시각 00:00~11:59에는 구약 줄, 12:00~23:59에는 신약 줄에 "지금" 표시를 해야 한다 (F-1 FR-2와 같은 경계)
- FR-5: 사용자가 줄을 누르면 시스템은 그 구분의 묵상 화면을 보여줘야 한다. 어느 구분을 보여줄지는 기기 시각이 아니라 누른 줄로 정한다
- FR-6: 읽음 표시된 줄을 누르면 시스템은 오늘 읽은 묵상의 화면을 보여주고, 진행 위치와 마친 날을 바꾸지 않아야 한다
- FR-7: 묵상 화면에서 메인으로 돌아오면 시스템은 메인의 읽음 표시를 최신 저장값으로 다시 정해야 한다 ("다 봤어요" 반영). 메인 줄을 마지막으로 정한 뒤 기기 로컬 날짜가 바뀌었으면 두 줄을 모두 다시 정한다(목록 검색 포함). 날짜가 그대로면 목록을 다시 검색하지 않는다 (9장 3번)
- FR-9: 사용자가 "다 봤어요"를 누르면 시스템은 진행 위치·마친 날을 저장한 뒤 "오늘 구약(신약) 묵상을 마쳤습니다" 화면을 거치지 않고 메인으로 돌아가야 한다 (9장 1번)
- FR-10: 다시 보기 화면(FR-6)에는 "다 봤어요" 버튼을 보이지 않아야 한다 (9장 2번)
- FR-8: 시스템은 구약·신약 줄을 따로 불러와야 한다. 한쪽 실패는 그 줄에만 안내 문구(M4 R-7과 같은 문구)와 "다시 시도"를 보이고, "다시 시도"는 그 줄만 다시 불러온다

## 5. 하지 않는 것
- 메인에서 읽음을 직접 체크·해제하기: 읽음은 "다 봤어요"로만 바뀐다 (2026-11-20 진성 결정: 표시만)
- 오늘 이전에 읽은 묵상 다시 보기: F-2 지난 묵상 목록에서 다룬다. 이 기능은 오늘 읽은 것 1개만 다시 연다
- 메인에서 영상 미리 보기, 설교문 일부 보여주기
- 진행 위치를 메인에서 바꾸기

## 6. 화면·사용 흐름
1. 앱을 연다 → 메인: 구약 줄, 신약 줄 (각 줄: 구분 이름, 날짜·본문 제목, "지금"/"읽음" 표시)
2. 줄을 누른다 → 그 구분의 묵상 화면 (M4 화면 재사용: 위 영상, 아래 날짜·본문·찬송·설교문, 맨 아래 "다 봤어요")
3. "다 봤어요" → 메인으로 돌아오면 그 줄에 "읽음"
- 기존 "오늘 구약(신약) 묵상을 마쳤습니다" 화면은 없앤다 (9장 1번). 그 자리를 메인의 "읽음" 표시가 대신한다

## 7. 기술적 고려
- 지금 앱은 실행 때 기기 시각으로 구분 하나를 고르고 그 하나만 불러온다 (코드 확인 `MorningDevotion/Screen/DevotionScreenModel.swift` `load()`, `refreshIfStale()`). 이 기능은 구분을 바깥에서 정하게 바꾼다 — 기존 M4 단위 테스트(시각으로 구분을 고르는 기준)와 닿는다
- 메인의 날짜·본문 제목은 목록 검색 결과에 있다 (코드 확인 `DevotionModels.swift:63-71` `DevotionEntry`의 `date`·`weekday`·`passageText`). 글 페이지를 가져오지 않아도 된다
- 요청 수: 메인을 열 때 다음 묵상 찾기를 구약·신약 둘 다 하므로, 목록 검색이 최대 14회(구분당 최대 7일, `NextDevotionSearch.swift:17`)다. 지금은 최대 7회. 평소(다음 날에 글이 있음)는 2회 (산수, 실측 아님)
- 읽음 판정은 기존 저장값 `readingProgress.finishedDayOld/New`를 쓴다 (코드 확인 `ReadingProgressStore.swift:15-16,51-58`). 저장 키를 새로 만들지 않는다
- 테스트 입력은 M4 fixture를 그대로 쓸 수 있다 (`cast-search-proverbs-23.html`, `cast-search-john-5.html`, `cast-search-date-*.html`) — 새 fixture 필요 여부는 설계 단계

## 8. 성공 지표
- 앱을 열었을 때 설교문이 아니라 메인이 먼저 나오는지 (시뮬레이터 육안)
- 메인 줄의 날짜·본문 제목이 그 줄을 눌러 연 묵상 화면의 날짜·본문과 같은지 (구약·신약 각각)

## 9. 결정 필요
모두 2026-11-20 진성 결정.
- "오늘 구약(신약) 묵상을 마쳤습니다" 화면을 메인에서도 쓰나? — **결정: 아니오, 없앤다.** "다 봤어요"를 누르면 바로 메인으로 돌아가고 그 줄에 "읽음"이 뜬다 (FR-9). F-1 9장 1번 A안 중 "그날 다음 묵상을 보여주지 않는다"는 메인의 읽음 줄(FR-2)로 유지된다
- 다시 보기 화면(US-4)에 "다 봤어요" 버튼을 보이나? — **결정: 아니오, 숨긴다** (FR-10)
- 메인으로 돌아올 때(FR-7) 읽지 않은 줄도 다시 검색하나? — **결정: 날짜가 바뀌었을 때만.** 같은 날이면 목록 검색 없이 읽음 표시만 갱신한다
