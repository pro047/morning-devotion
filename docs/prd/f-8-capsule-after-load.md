# PRD: F-8 글을 다 불러온 뒤에 캡슐 보이기

작성일: 2026-11-26 · 프로젝트 PRD: [00-project.md](00-project.md) · 관련: [f-5-glass-nav-swipe.md](f-5-glass-nav-swipe.md), [f-7-finish-in-capsule.md](f-7-finish-in-capsule.md)

## 1. 개요
묵상 화면에 들어가면 글을 불러오는 동안 하단의 이전·다음 캡슐(`‹ · ›`)이 화면 바닥이 아니라 가운데, 불러오는 중 표시 바로 아래에 뜬다.
진성은 글을 다 불러온 뒤에 캡슐이 보이기를 원한다.
이 기능은 묵상 화면에 글이 보이는 동안에만 캡슐을 보이고, 불러오는 중·네트워크 오류 화면에서는 캡슐을 숨긴다.

## 2. 목표
- 묵상 화면에 들어간 뒤 글이 뜨기 전까지 화면 가운데에 캡슐이 보이지 않는다
- 글이 뜨면 캡슐이 화면 바닥에 보인다

## 3. 사용자 스토리

### US-1: 글이 뜬 뒤에만 캡슐
**설명:** 진성으로서, 묵상 화면에 들어갈 때 글을 다 불러온 뒤에 이전·다음 캡슐을 보고 싶다. 불러오는 동안 캡슐이 화면 가운데에 떠 있어 어색하기 때문이다.
**수용 기준:**
- [ ] 묵상 화면에 들어가 글을 불러오는 중에는 캡슐이 화면 어디에도 보이지 않는다
- [ ] 글이 보이면 캡슐이 화면 하단 가운데에 보인다 (F-5 US-2 위치)
- [ ] 캡슐은 글과 같은 순간에 애니메이션 없이 나타난다
- [ ] 네트워크 오류 화면("인터넷 연결을 확인해 주세요" / "다시 시도")에서는 캡슐이 보이지 않는다
- [ ] 네트워크 오류 화면에서 "다시 시도"를 눌러 글을 불러오는 동안에도 캡슐이 보이지 않고, 글이 뜨면 바닥에 보인다
- [ ] `‹`·`›` 나 스와이프로 이동 검색하는 동안에는 지금처럼 캡슐이 보이고 가운데에 불러오는 중 표시가 있다 (캡슐이 사라졌다 나타나지 않는다)
- [ ] 이동한 글을 불러오다 네트워크 오류 화면이 되면 캡슐이 보이지 않는다

## 4. 기능 요구사항
- FR-1: 묵상 화면 하단 캡슐은 글이 보이는 상태에서만 보여야 한다
- FR-2: 글을 불러오는 중이거나 네트워크 오류 화면이면 캡슐을 보이지 않아야 한다
- FR-3: 이동 검색 중에는 지금 글이 보이는 상태로 남아 있으므로 캡슐이 계속 보여야 한다 (F-5·F-7 동작 그대로)
- FR-4: 캡슐이 보일 때의 내용(`‹`·`›`, 가운데 점·"다 봤어요"·불러오는 중 표시)과 동작은 바꾸지 않는다

## 5. 하지 않는 것
- 캡슐이 나타날 때의 페이드 등 애니메이션 — 진성이 "바로 나타남"을 골랐다 (2026-11-26)
- 네트워크 오류 화면에서 이전·다음으로 이동하는 다른 수단 추가 — 오류 화면에서는 "다시 시도"만 쓴다 (2026-11-26 진성 결정)
- 불러오는 중 표시·네트워크 오류 화면 자체의 모양 변경
- 메인 화면 변경
- 본문 스크롤이 가끔 잘 안 되는 문제 — 재현되지 않아 이 기능 범위 밖이다

## 6. 화면·사용 흐름
- 진입: 불러오는 중 표시만 보임 (캡슐 없음) → 글이 뜸 + 하단 캡슐 `‹ · ›` 또는 `‹ 다 봤어요 ›`
- 진입 실패: 네트워크 오류 화면 (캡슐 없음) → "다시 시도" → 불러오는 중 (캡슐 없음) → 글 + 캡슐
- 이동: 글 + 캡슐 `‹ (불러오는 중) ›` → 새 글 + 캡슐 (지금과 같음)

## 7. 기술적 고려
- 이 기능은 F-7 US-1 수용 기준 "글을 불러오는 중이거나 네트워크 오류 화면에서는 캡슐 가운데가 점(●)이다"를 대체한다. 그 상태에서는 캡슐 자체가 없다
- 지금 캡슐이 가운데에 뜨는 것은 캡슐이 화면이 아니라 본문 영역 아래에 붙어 있고, 불러오는 중·오류 화면의 본문 영역이 작기 때문으로 보인다 (코드 확인 기준 추정, 실기기 실측 아님)
- 캡슐 표시 여부는 단위 테스트로 판정하기 어렵다. 모양은 시뮬레이터 스크린숏과 실기기로 확인한다

## 8. 성공 지표
- `xcodebuild test` 통과 (`.sap/config` 의 `TEST_CMDS`)
- 시뮬레이터(iPhone 17, iOS 27.2) 스크린숏: 불러오는 중 화면에 캡슐 없음, 글이 뜬 화면 하단에 캡슐 있음
- 실기기(무선 설치): 묵상 화면에 들어갈 때 불러오는 중에는 캡슐이 안 보이고 글이 뜨면 바닥에 나타난다
