# PRD: F-1 M1 다음 묵상 고르기

작성일: 2026-11-20 · 상위 PRD: [f-1-next-devotion.md](f-1-next-devotion.md) · 프로젝트 PRD: [00-project.md](00-project.md)

F-1 을 4개 마일스톤으로 나눈 것 중 **M1** 이다. 이 문서가 이번 범위의 정본이고, F-1 PRD 는 배경으로만 읽는다.

## 1. 범위
교회 홈페이지 묵상 **목록 HTML** 을 입력으로 받아, 진행 위치와 현재 시각으로 **다음 묵상(날짜·본문)** 을 고르는 로직.
네트워크·저장·화면은 범위 밖이다. 순수 로직과 단위 테스트만 만든다.

대응하는 F-1 요구: FR-2, FR-3, FR-7, US-1 의 수용 기준 앞 두 개.

## 2. 요구사항
- R-1 (FR-2): 현재 시각으로 구분을 정한다. 00:00~11:59 → 구약, 12:00~23:59 → 신약
  - **현재 시각은 인자(Date 와 Calendar/TimeZone)로 받는다.** 함수 안에서 `Date()` 를 직접 부르지 않는다 — 경계(11:59/12:00) 테스트가 불가능해진다
- R-2: 목록 HTML 에서 묵상 제목을 뽑아 (날짜, 요일, 본문[책·장·절 구간], 작성자) 로 파싱한다
- R-3 (FR-7): 제목 표기 차이를 같은 것으로 다룬다
  - 따옴표 `“` `”` `"`
  - 구간 기호 `-` `~`
  - 날짜 뒤 공백 유무: `2026/11/17 (화)` 와 `2026/11/16(월)`
  - HTML 엔티티: 오래된 글은 `:` 가 `&#58;` 로 온다 (실측: `"잠언 23&#58;1~35"`, `작성&#58; 김효진`)
- R-4 (FR-3): 다음 묵상 = 따라가는 묶음(연도)의 묵상 중 마지막으로 본 날짜 **직후에 목록에 존재하는 날짜** 의 글
  - "날짜 + 1일" 이 아니다. 2020/07/11(토) 다음은 2020/07/13(월)이다 (일요일 묵상 없음)
  - 다른 연도 글과 검색 잡음이 섞여 있어도 따라가는 묶음의 글만 고른다
  - 묶음에 직후 글이 없으면 "없음" 을 돌려준다 (안내 문구는 M4 범위)
