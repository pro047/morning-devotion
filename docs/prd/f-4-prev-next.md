# PRD: F-4 이전·다음 묵상 이동 (하루 하나 제한 해제)

작성일: 2026-11-22 · 프로젝트 PRD: [00-project.md](00-project.md) · 관련: [f-3-main-page.md](f-3-main-page.md), [f-1-next-devotion.md](f-1-next-devotion.md)

## 1. 개요
지금은 하루에 구약·신약 묵상을 하나씩만 볼 수 있다. "다 봤어요"를 누르면 메인의 그 줄이 그날 내내 "읽음"으로 남고, 다음 묵상은 날짜가 바뀌어야 나온다 (F-3 9장 1번, F-1 9장 1번 A안).
진성은 "하루에 말씀 묵상 하나씩이 강제되는데 좀 더 유연하게" 하고 싶다고 했다 (2026-11-22). 다만 하루 제한을 없애면 그날 읽은 글을 다시 볼 길도 사라지므로, "이전·다음 기능이 있어야 할 것 같다"고 했다.
이 기능은
1. 하루 제한을 없앤다 — "다 봤어요"를 누르면 메인으로 돌아가고, 그 줄이 바로 다음 묵상으로 바뀐다
2. 묵상 화면과 메인 줄에서 이전·다음 묵상으로 옮겨 가며 볼 수 있게 한다
3. 이미 읽은 글은 "읽음"으로 표시한다. "읽음"은 그날 눌렀는지가 아니라 **진행 위치까지 읽었는지**로 정한다

이 기능은 F-3 9장 1번 중 "그날 다음 묵상을 보여주지 않는다"와 F-3 US-3·US-4, F-1 9장 1번 A안을 대체한다.

## 2. 목표
- 같은 날 구약(신약)을 두 개 이상 이어서 읽을 수 있다
- 방금 읽은 글을 이전 이동으로 다시 열 수 있다
- 진행 위치가 실수로 뒤로 되돌아가지 않는다

## 3. 사용자 스토리

예시 날짜: 빈 저장소의 구약 진행 위치 기본값은 2025/09/10, 신약은 2020/07/11이다. 구약 다음 글은 "2025/09/11(목) 잠언 23:24-35", 그다음은 "2025/09/12(금) 잠언 24:1-10"이다. 신약 다음 글은 "2020/07/13(월) 요한복음 5:30-47", 그다음은 "2020/07/14" 글이다.

### US-1: 같은 날 이어서 읽기
**설명:** 진성으로서, 하나를 다 본 뒤 같은 날 다음 묵상도 이어서 읽고 싶다. 시간이 있는 날 더 읽고 싶기 때문이다.
**수용 기준:**
- [ ] 빈 저장소에서 2026-11-22에 구약 "2025/09/11(목) 잠언 23:24-35"의 "다 봤어요"를 누르면 메인으로 돌아오고, 구약 줄은 "읽음" 없이 "2025/09/12(금) 잠언 24:1-10"을 보여준다
- [ ] 같은 날 메인의 구약 줄을 눌러 "2025/09/12(금) 잠언 24:1-10"의 "다 봤어요"를 누르면 메인 구약 줄은 2025/09/12 다음 글로 바뀐다
- [ ] 위 두 번 모두 신약 줄과 신약 진행 위치는 바뀌지 않는다
- [ ] 신약도 같은 방식으로 동작한다 ("2020/07/13(월) 요한복음 5:30-47" → "다 봤어요" → 메인 신약 줄이 2020/07/14 글)
- [ ] "다 봤어요"를 누른 날짜를 따로 저장하지 않는다. 앱을 지웠다 다시 깔지 않고 업데이트해도, 업데이트 전에 그날 "다 봤어요"를 눌렀던 줄이 "읽음"으로 남지 않는다

### US-2: 묵상 화면에서 이전·다음으로 이동하기
**설명:** 진성으로서, 묵상 화면에서 앞뒤 날짜의 묵상으로 바로 넘어가고 싶다. 방금 읽은 글을 다시 보거나 다음 글을 미리 보기 위해서다.
**수용 기준:**
- [ ] 구약 "2025/09/12(금) 잠언 24:1-10" 묵상 화면에서 "이전"을 누르면 "2025/09/11(목) 잠언 23:24-35" 묵상 화면(영상·글)이 나온다
- [ ] 그 화면에서 "다음"을 누르면 다시 "2025/09/12(금) 잠언 24:1-10" 묵상 화면이 나온다
- [ ] "다음"은 진행 위치와 관계없이 계속 누를 수 있다 (안 읽은 글을 지나 더 뒤의 글로도 간다)
- [ ] 이전·다음은 같은 구분 안에서만 움직인다. 구약 화면에서 "다음"을 눌러도 신약 글이 나오지 않는다
- [ ] 이전·다음으로 글을 옮겨 보기만 해서는 진행 위치가 바뀌지 않는다

### US-3: 읽음 표시와 읽은 글의 "다 봤어요"
**설명:** 진성으로서, 지금 보는 글을 이미 읽었는지 알고 싶다. 그리고 읽은 글을 다시 볼 때 진행 위치가 실수로 되돌아가지 않으면 좋겠다.
**수용 기준:**
- [ ] 구약 진행 위치가 2025/09/12일 때, "2025/09/11"·"2025/09/12" 글의 묵상 화면에는 "읽음" 표시가 있고 "다 봤어요" 버튼이 없다
- [ ] 같은 상태에서 2025/09/12 다음 글의 묵상 화면에는 "읽음" 표시가 없고 "다 봤어요" 버튼이 있다
- [ ] 읽은 글을 이전 이동으로 열어 봐도 구약 진행 위치(2025/09/12)는 바뀌지 않는다
- [ ] 메인 줄이 읽은 글을 보여줄 때(US-4) 그 줄에 "읽음" 표시가 있다. 안 읽은 글이면 없다

### US-4: 메인 줄에서 이전·다음으로 넘겨 보기
**설명:** 진성으로서, 메인에서 구약·신약 줄을 앞뒤로 넘겨 원하는 날짜의 글을 고른 뒤 들어가고 싶다.
**수용 기준:**
- [ ] 메인을 열면 각 줄은 진행 위치 다음 글(안 읽은 첫 글)을 보여준다
- [ ] 구약 진행 위치가 2025/09/12일 때 메인 구약 줄의 "이전"을 누르면 줄이 "2025/09/12(금) 잠언 24:1-10"과 "읽음"으로 바뀐다. 이때 묵상 화면은 열리지 않는다
- [ ] 그 상태에서 줄을 누르면 "2025/09/12(금) 잠언 24:1-10" 묵상 화면이 열린다
- [ ] 구약 줄을 넘겨도 신약 줄은 바뀌지 않는다
- [ ] 메인 줄을 넘겨도 진행 위치는 바뀌지 않는다

### US-5: 더 갈 글이 없거나 불러오지 못할 때
**설명:** 진성으로서, 이전·다음으로 갈 글이 없거나 인터넷 문제로 못 가면 그 이유를 알고 싶다.
**수용 기준:**
- [ ] 지금 글 다음 7일 안에 같은 구분의 글이 없으면 "다음"을 눌렀을 때 "다음 묵상을 찾지 못했습니다"가 보이고 지금 보던 글은 그대로다
- [ ] 지금 글 이전 7일 안에 같은 구분의 글이 없으면 "이전"을 눌렀을 때 "이전 묵상을 찾지 못했습니다"가 보이고 지금 보던 글은 그대로다
- [ ] 이전·다음 이동 중 목록 검색이 네트워크 오류면 "인터넷 연결을 확인해 주세요"가 보이고 지금 보던 글은 그대로다
- [ ] 위 경우 모두 진행 위치는 바뀌지 않는다

## 4. 기능 요구사항
- FR-1: 시스템은 구분마다 "마친 날"(`readingProgress.finishedDayOld`·`readingProgress.finishedDayNew`)을 더 이상 저장하지도 읽지도 않아야 한다
- FR-2: 글의 읽음 여부는 "그 글의 날짜가 그 구분의 진행 위치(마지막으로 본 날짜) 이하"로 정해야 한다
- FR-3: 메인 줄의 기본 글은 날짜와 관계없이 항상 진행 위치 다음 글이어야 한다 (F-1 FR-3, M4 R-1과 같은 날짜 검색)
- FR-4: 사용자가 안 읽은 글에서 "다 봤어요"를 누르면 시스템은 그 구분의 진행 위치를 그 글의 날짜로 바꾸고 메인으로 돌아가야 한다
- FR-5: 읽은 글(FR-2)의 묵상 화면에는 "다 봤어요"를 보이지 않아야 한다. 따라서 진행 위치는 "다 봤어요"로 뒤로 가지 않는다 (F-1 M2 D:291 "이르거나 같아도 덮어쓴다"를 화면 쪽에서 막음)
- FR-6: 묵상 화면에 "이전"·"다음"이 있어야 하고, 누르면 같은 구분에서 지금 글의 바로 앞(뒤) 날짜 글의 묵상 화면을 보여줘야 한다
- FR-7: 메인의 구약·신약 줄마다 "이전"·"다음"이 있어야 하고, 누르면 그 줄만 앞(뒤) 글로 바뀌어야 한다. 묵상 화면은 열지 않는다
- FR-8: 앞(뒤) 글은 지금 글 날짜의 1일 전(후)부터 하루씩 최대 7일 날짜 검색으로 찾는다 (다음 쪽은 `NextDevotionSearch` 와 같은 범위)
- FR-9: 이전·다음 이동과 메인 줄 넘기기는 진행 위치를 바꾸지 않아야 한다
- FR-10: 앞(뒤) 글을 못 찾거나 네트워크 오류면 지금 보던 글을 유지하고 US-5의 문구를 보여야 한다

## 5. 하지 않는 것
- 지난 묵상 목록에서 골라 보기 — F-2로 따로 한다
- 날짜를 직접 입력하거나 달력에서 고르기
- 진행 위치를 사용자가 직접 앞뒤로 옮기기 (진행 위치는 "다 봤어요"로만 앞으로 간다)
- 구약·신약을 넘나드는 이동
- "오늘 몇 개 읽었는지" 같은 하루 단위 집계

## 6. 화면·사용 흐름
1. 메인: 구약·신약 두 줄. 줄마다 날짜·본문 제목, "지금" 배지(기존 12시 규칙), 읽은 글이면 "읽음", 그리고 "이전"·"다음"
2. 줄을 누르면 그 줄이 보여주던 글의 묵상 화면(영상·글)
3. 묵상 화면: "이전"·"다음", 읽은 글이면 "읽음" 표시, 안 읽은 글이면 맨 아래 "다 봤어요"
4. "다 봤어요" → 메인, 그 줄은 새 진행 위치의 다음 글
- 디자인은 기존 `Theme.swift`의 메인 카드(Liquid Glass)·종이 배경을 따른다

## 7. 기술적 고려
- 지금 "읽음"과 다시 보기는 마친 날 = 오늘일 때만 성립한다 (`MainScreenState.swift:70-74`, `ReadingProgressStore.swift:15-16`, `DevotionScreenState.swift:24` `.review`). 이 분기와 그 테스트(`MainScreenStateTests`·`MainScreenModelTests`·`DevotionScreenModelTests`·`ReadingProgressStoreTests`)가 바뀐다 — 기대값이 바뀌는 테스트는 설계에서 목록으로 밝힌다
- 기기에는 이미 마친 날 키가 남아 있을 수 있다 (2026-11-22 실기기 설치본). FR-1에 따라 읽지 않는다
- 이전 쪽 날짜 검색은 지금 코드에 없다. 다음 쪽은 `NextDevotionSearch` (최대 7일)
- 요청 수: 이전·다음 한 번에 목록 검색 1~7회 (산수, 실측 아님). 묵상 화면 이동은 여기에 글 페이지 1회, 영상이 글에 없으면 YouTube `search.list` 1회가 더해진다

## 9. 결정 필요
- 메인 줄을 넘겨 둔 상태(US-4)는 메인을 떠났다 돌아오면 진행 위치 다음 글로 되돌아가나? — 아니오면 넘겨 둔 글이 앱을 다시 열 때까지 남는다
- 진행 위치보다 두 칸 이상 뒤의 안 읽은 글(건너뛴 글)에서 "다 봤어요"를 보이나? — 예면 누를 때 사이의 글들도 "읽음"이 된다(FR-2). 아니오면 "다 봤어요"는 진행 위치 다음 글에서만 보인다
- 묵상 화면에서 "다음"으로 다른 글로 옮길 때 메인을 거치지 않고 화면 안에서 바뀌나? — 아니오면 화면이 새로 쌓여 뒤로 가기가 여러 번 필요하다
- 메인 줄의 "이전"·"다음"을 눌러 목록을 찾는 동안 그 줄에 불러오는 중 표시를 하나? — 아니오면 1~7회 검색 동안 줄이 그대로 멈춰 보인다
