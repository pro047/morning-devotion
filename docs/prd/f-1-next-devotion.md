# PRD: F-1 다음 묵상 이어보기

작성일: 2026-11-20 · 프로젝트 PRD: [00-project.md](00-project.md)

## 1. 개요
진성은 100주년기념교회의 지난 새벽 묵상을 순서대로 이어서 본다. 아침에는 구약(2025년 묶음), 점심에는 신약(2020년 묶음)이다.
지금은 어제 본 장·절을 기억해 두고, 다음 본문을 구글과 유튜브에서 매번 따로 검색한다.
이 기능은 그 일을 앱이 대신한다.
1. 지금 시간대에 맞는 다음 묵상을 찾는다
2. 그 묵상의 글과 영상을 한 화면에 보여준다
3. 진성이 "다 봤어요"를 누르면 진행 위치를 넘긴다

## 2. 목표
- 앱을 열면 검색 없이 지금 시간대의 다음 묵상 글과 영상이 나온다
- 앱이 구약·신약 각각 마지막으로 본 묵상을 기억하고, 다음 날 그 다음 묵상을 보여준다

## 3. 사용자 스토리

### US-1: 시간대에 맞는 다음 묵상 글 보기
**설명:** 진성으로서, 앱을 열면 지금 시간대의 다음 묵상 글을 바로 읽고 싶다. 매번 장·절을 기억해서 구글을 검색하는 게 번거롭기 때문이다.
**수용 기준:**
- [ ] 진행 위치가 구약 "2025/09/10 잠언 23:12-23"일 때 아침에 앱을 열면 "2025/09/11(목) 잠언 23:24-35" 묵상이 나온다
- [ ] 진행 위치가 신약 "2020/07/11 요한복음 5:19-29"일 때 점심 이후에 앱을 열면 "2020/07/13(월) 요한복음 5:30-47" 묵상이 나온다
- [ ] 화면에 묵상 날짜, 본문(성경 장·절), 찬송, 설교문 글이 보인다
- [ ] 설교문 글에는 홈페이지의 메뉴·버튼 같은 글 아닌 요소가 섞여 있지 않다
- [ ] 같은 본문이 다른 해 묶음에도 있을 때(예: 요한복음 5:30-47은 2015/06/22와 2020/07/13), 따라가는 묶음의 글이 나온다

### US-2: 같은 묵상의 영상 앱 안에서 보기
**설명:** 진성으로서, 글과 같은 날짜·본문의 묵상 영상을 앱 안에서 바로 보고 싶다. 유튜브에서 따로 검색하지 않기 위해서다.
**수용 기준:**
- [ ] "2025/09/11(목) 잠언 23:24-35" 묵상 화면에서 글 페이지에 걸린 "[ 생방송 | 새벽기도회 | 2025.9.11(목) ] 잠언 23:24-35 | 인도 김광욱" 영상(`PR9GK_S83NU`)이 재생된다 (2026-11-20 결정: 설교 편집본이 아니라 생방송 영상이어도 된다 — 재생 위치는 진성이 직접 조절)
- [ ] "2020/07/13(월) 요한복음 5:30-47" 묵상 화면에서 100주년기념교회 채널의 "2020/07/13(월) “요한복음 5:30-47” / 박성호" 영상이 재생된다
- [ ] 영상은 유튜브 앱으로 넘어가지 않고 앱 화면 안에서 재생된다
- [ ] 맞는 영상을 찾지 못하면 영상 자리에 "영상을 찾지 못했습니다"가 보이고, 글은 그대로 읽을 수 있다

### US-3: "다 봤어요"로 진행 위치 넘기기
**설명:** 진성으로서, 묵상을 마치면 "다 봤어요"를 눌러 기록하고 싶다. 그래야 다음 날 앱이 이어서 보여주기 때문이다.
**수용 기준:**
- [ ] "2025/09/11 잠언 23:24-35" 화면에서 "다 봤어요"를 누르면 구약 진행 위치가 그 묵상으로 바뀐다
- [ ] 다음 날 아침 앱을 열면 2025/09/11 직후의 구약 묵상이 나온다
- [ ] "다 봤어요"를 누르지 않고 앱을 닫았다 다시 열면 같은 묵상이 그대로 나온다
- [ ] 구약에서 "다 봤어요"를 눌러도 신약 진행 위치는 바뀌지 않는다 (반대도 같다)
- [ ] 앱을 완전히 종료했다가 다시 실행해도 진행 위치가 유지된다

### US-4: 처음 진행 위치 정하기
**설명:** 진성으로서, 앱을 처음 쓸 때 지금까지 본 위치에서 시작하고 싶다. 이미 구약은 잠언, 신약은 요한복음까지 와 있기 때문이다.
**수용 기준:**
- [ ] 처음 실행한 뒤 구약 진행 위치를 "2025/09/10 잠언 23:12-23", 신약 진행 위치를 "2020/07/11 요한복음 5:19-29"로 정할 수 있다
- [ ] 위치를 정한 직후 US-1의 두 기준처럼 다음 묵상이 나온다

### US-5: 묵상을 가져오지 못했을 때 알리기
**설명:** 진성으로서, 다음 묵상을 가져오지 못하면 이유를 알고 싶다. 빈 화면만 보면 앱 문제인지 인터넷 문제인지 모르기 때문이다.
**수용 기준:**
- [ ] 인터넷이 끊긴 상태에서 앱을 열면 "인터넷 연결을 확인해 주세요"가 보이고, "다시 시도" 버튼이 있다
- [ ] 따라가는 묶음에 마지막으로 본 날짜 이후의 글이 없으면 "다음 묵상을 찾지 못했습니다"가 보인다
- [ ] 위 두 경우 모두 진행 위치는 바뀌지 않는다

## 4. 기능 요구사항
- FR-1: 시스템은 구약과 신약 각각 "따라가는 묶음(연도)"과 "마지막으로 본 묵상(날짜·본문)"을 기기에 저장해야 한다
- FR-2: 시스템은 기기의 현재 시각으로 시간대를 정해야 한다. 00:00~11:59는 구약, 12:00~23:59는 신약이다
- FR-3: 시스템은 다음 묵상을 이렇게 골라야 한다: 따라가는 묶음의 묵상 중 마지막으로 본 날짜 **직후 날짜**의 글
- FR-4: 시스템은 교회 홈페이지의 묵상 글에서 날짜, 본문(장·절), 찬송, 설교문 글을 뽑아 앱 화면에 맞게 보여줘야 한다
- FR-5: 시스템은 묵상과 날짜·본문이 같은 영상을 앱 안에서 재생해야 한다. 영상은 먼저 묵상 글 페이지에 걸린 유튜브 영상(`youtube.com/embed/<id>`)을 쓰고, 글 페이지에 없을 때만 100주년기념교회 유튜브 채널에서 찾는다 (2026-11-20 결정: C안)
- FR-6: 사용자가 "다 봤어요"를 누르면 시스템은 해당 구분(구약 또는 신약)의 마지막으로 본 묵상을 화면의 묵상으로 바꿔야 한다
- FR-7: 시스템은 홈페이지 제목의 표기 차이를 같은 것으로 다뤄야 한다. 따옴표 `“` `"`, 구간 기호 `-` `~`, 날짜 뒤 공백 유무(`2026/11/17 (화)` 와 `2026/11/16(월)`)가 해당한다
- FR-8: 시스템은 묵상 글이나 영상을 가져오지 못하면 진행 위치를 바꾸지 않고, US-5의 안내 문구를 보여줘야 한다

## 5. 하지 않는 것
- 지난 묵상 목록과 다시 보기: F-2에서 다룬다
- 시간대와 다른 구분의 묵상 보기 (예: 아침에 신약 보기): 결정 필요에 질문으로 둔다
- 묵상 시각 알림
- 영상 후보 여러 개 중 고르기: 날짜·본문이 같은 교회 채널 영상 하나만 쓴다
- 다른 교회·다른 채널 영상

## 6. 화면·사용 흐름
1. 앱을 연다 → 현재 시각으로 구약·신약 중 하나를 정한다
2. 다음 묵상 화면: 위에 영상, 아래에 날짜·본문·찬송·설교문 글, 맨 아래 "다 봤어요" 버튼
3. "다 봤어요"를 누른다 → 진행 위치가 바뀐다 (누른 뒤 화면이 무엇을 보여줄지는 결정 필요)

## 7. 기술적 고려
아래는 2026-11-20에 curl로 직접 조회한 결과다.
- **교회 홈페이지 접근**: HTTP 200, UTF-8. 기본 curl과 아이폰 Safari User-Agent 둘 다 응답한다
- **묵상 목록**: `https://100church.org/home/board.php?board=cast&config=6&category=6`
  - 제목 형식: `2026/11/20(금) “에스겔 28:1-10” / 작성: 김현욱`
  - 글 링크: `command=body&no=<글번호>&body_only=y&button_view=n`
- **검색**: 같은 주소에 `search=<검색어>`, `shwhere=subject|tbody`를 붙이면 된다
  - `shwhere`에 본문(`tbody`)이 포함돼 있어 관계없는 글도 섞여 나온다 (예: `요한복음 5:30` 검색에 `누가복음 5:27~39`)
- **묵상 글 첫머리 형식**:
  ```
  2009년 11월 25일 (수)
  <본문> 마태복음 1:1-25/218장(새286) '주 예수님 내 맘에 오사'
  ```
- **글 페이지의 영상** (2026-11-20 실측, 그 달 마지막 글 표본): 2022~2025 글 페이지에는 유튜브 영상 id 가 있고, 2020~2021 글에는 없다
  - 2023~2025 (18/18건): 본문 안 `<iframe src=".../youtube.com/embed/<id>">`
  - 2022 (2/2건): iframe 이 아니라 본문 제목 링크 `<a href="https://www.youtube.com/embed/<id>">`
  - 2020~2021 (0/4건, fixture 11480 포함): 영상 없음 → 유튜브에서 따로 찾아야 한다
  - 영상이 시작된 경계는 2021/06 ~ 2022/01 사이 (정확한 날짜 미측정). 한 달 안에서 섞이는지도 미측정
  - 2025 글에 걸린 영상 제목은 `[ 생방송 | 새벽기도회 | … ]` 형식이다 (설교 편집본 아님)
- **유튜브 영상 제목**: 채널 이름은 `100주년기념교회`이고, 연도마다 제목 형식이 다르다
  - 2020년: `2020/07/13(월) “요한복음 5:30-47” / 박성호`
  - 2022년: `2022/01/31(월) "창세기 32:1-20" / 김남빈` (글 페이지 링크의 영상)
  - 2023년: `2023/01/31(화) “신명기 27:1-10” / 유영진` (글 페이지 링크의 영상)
  - 2025년: `[ 설교 | 새벽기도회 | 2025.9.11(목) ] 잠언 23:24-35 | 인도 김광욱` (채널 검색), 글 페이지에 걸린 것은 `[ 생방송 | 새벽기도회 | 2025.9.11(목) ] 잠언 23:24-35 | 인도 김광욱`
- **유튜브 검색 방법**: 글 페이지에 영상이 없을 때만 YouTube Data API를 쓴다 (2026-11-20 확정, 진성이 API 키를 발급한다. 같은 날 C안으로 범위를 좁힘 — 지금 따라가는 묶음 중 신약 2020이 해당). 할당량 숫자는 확인하지 않았다
- **API 키 보관**: API 키는 git 저장소에 커밋하지 않는다
- **2015년 영상**: `100주년기념교회 2015/06/22 요한복음 5:30-47` 검색 상위에 교회 채널 영상이 없었다. 신약은 2020년 묶음을 따라가므로 1차에는 영향이 없다

## 8. 성공 지표
- 앱이 보여준 다음 묵상이 진성이 직접 고를 다음 묵상과 같은지. 구약·신약 각각 "다 봤어요"를 누를 때마다 대조한다
- 앱이 재생한 영상과 글의 날짜·본문이 같은지
- 이 기능을 쓰는 동안 묵상을 위해 유튜브·구글을 검색한 횟수 (목표 0회)

## 9. 결정 필요
- 구약 "다 봤어요"를 누른 뒤 같은 아침에 다음 구약 묵상을 바로 보여주나? — 아니오면 "오늘 구약 묵상을 마쳤습니다"를 보여준다
  - 2026-11-20: M4(화면)에서 정하기로 미룸
- 시간대와 다른 구분(예: 아침에 신약)으로 바꿔 보는 버튼이 필요한가? — 아니오면 점심 묵상을 놓친 날은 다음 날 점심까지 신약을 볼 수 없다
- 교회 채널 영상이 앱 안 재생(임베드)을 허용하나? — 아니오면(퍼가기 금지 영상) 그 영상은 유튜브 앱으로 넘겨서 연다. 아직 확인하지 않았다
  - 2026-11-20: 글 페이지 영상 6건의 oEmbed(`youtube.com/oembed`) 가 모두 200 — 허용일 가능성이 높지만, 퍼가기 금지면 oEmbed 가 401 이라는 동작 자체는 추정이다. 앱에서 재생해 봐야 확정
- 처음 진행 위치를 앱 안에서 진성이 직접 입력하나? — 아니오면 2026-11-20 기준 위치(00-project.md 3장 표)를 앱에 미리 넣어 둔다
  - **결정(2026-11-20): 아니오, 미리 넣어 둔다.** 저장된 값이 없을 때만 넣는다. 이유: 사용자가 진성 1명이고 시작 위치가 이미 정해져 있으며, 입력 화면은 M4 라 M2 에서 검증할 수 없다. 다른 위치에서 다시 시작하려면 코드를 고친다
- 따라가는 묶음의 다음 날짜 글이 홈페이지에는 있는데 영상이 없을 때, 같은 본문의 다른 해 영상을 대신 보여주나? — 아니오면 US-2의 "영상을 찾지 못했습니다"를 보여준다
