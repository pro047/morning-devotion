# PRD: F-9 성경 본문 바텀시트

작성일: 2026-11-26 · 프로젝트 PRD: [00-project.md](00-project.md) · 관련: [f-6-sermon-video.md](f-6-sermon-video.md), [f-8-capsule-after-load.md](f-8-capsule-after-load.md)

## 1. 개요
진성은 묵상 글을 읽으면서 그날 성경 본문(예: 잠언 23:24-35)을 앱 안에서 같이 보고 싶다.
지금은 묵상 화면에 본문 제목 글자만 있고 성경 구절은 없다.
이 기능은 묵상 화면에 떠 있는 버튼(플로팅 버튼)을 두고, 누르면 아래에서 올라오는 시트(바텀시트)에 그날 묵상 범위의 성경 구절을 개역개정으로 보인다.
구절은 대한성서공회 온라인 성경 웹페이지에서 그때그때 받아온다 (B안, 2026-11-26 진성 결정).

## 2. 목표
- 묵상 화면에서 버튼 한 번으로 그날 묵상 범위의 성경 구절을 읽는다
- 보이는 구절의 글자가 묵상 글이 인용하는 번역(개역개정)과 같다

## 3. 사용자 스토리

### US-1: 버튼을 눌러 성경 본문 보기
**설명:** 진성으로서, 묵상 화면에서 버튼을 눌러 그날 성경 본문을 보고 싶다. 묵상 글을 읽다가 본문을 다시 확인하려면 지금은 앱 밖에서 찾아야 하기 때문이다.
**수용 기준:**
- [ ] 묵상 화면에 글이 보이면 성경 본문 플로팅 버튼이 보인다
- [ ] 버튼을 누르면 바텀시트가 올라오고, 맨 위에 본문 제목(예: `잠언 23:24-35`)이 보인다
- [ ] 바텀시트에는 묵상 범위의 절만 보인다 — `잠언 23:24-35` 이면 24절부터 35절까지, 23절·36절은 없다
- [ ] 각 절 앞에 절 번호가 보인다
- [ ] 2025/09/11 `잠언 23:25` 는 "네 부모를 즐겁게 하며 너를 낳은 어미를 기쁘게 하라" 로 보인다 (개역개정. 개역한글이면 "너 낳은")
- [ ] 2020/07/13 `요한복음 5:31` 은 "증언하면" 으로 보인다 (개역개정. 개역한글이면 "증거하면")
- [ ] 바텀시트를 아래로 내리거나 바깥을 누르면 닫히고, 묵상 화면은 연 전과 같은 스크롤 위치다
- [ ] 바텀시트 안의 구절은 위아래로 스크롤된다

### US-2: 장을 넘는 본문
**설명:** 진성으로서, 본문이 두 장에 걸친 묵상(예: `창세기 31:55-32:12` 형식)도 전부 보고 싶다.
**수용 기준:**
- [ ] 본문이 두 장에 걸치면 앞 장의 시작 절부터 그 장 끝까지, 이어서 뒤 장의 1절부터 끝 절까지 보인다
- [ ] 두 장 사이에 뒤 장 번호가 보여 어디서 장이 바뀌는지 알 수 있다

### US-3: 못 불러올 때
**설명:** 진성으로서, 성경을 못 불러와도 묵상 글은 그대로 읽고 싶다.
**수용 기준:**
- [ ] 성경을 받아오지 못하면(네트워크 오류·HTTP 오류·페이지를 읽지 못함) 바텀시트 안에 "인터넷 연결을 확인해 주세요" 가 보인다
- [ ] 이때 묵상 화면(영상·설교 글)은 바뀌지 않는다
- [ ] 본문 제목을 장·절로 읽지 못한 묵상(`passage` 없음)에서는 플로팅 버튼이 보이지 않고, 성경 요청을 보내지 않는다
- [ ] 묵상 화면이 불러오는 중이거나 네트워크 오류 화면이면 플로팅 버튼이 보이지 않는다 (F-8 캡슐과 같은 규칙)

### US-4: 다른 묵상으로 옮긴 뒤
**설명:** 진성으로서, 이전·다음으로 옮긴 뒤 버튼을 누르면 옮긴 묵상의 본문을 보고 싶다.
**수용 기준:**
- [ ] `‹`·`›` 나 스와이프로 다른 묵상으로 옮긴 뒤 버튼을 누르면, 옮긴 묵상의 본문 제목과 구절이 보인다

## 4. 기능 요구사항
- FR-1: 시스템은 묵상 글이 보이는 상태이고 본문을 장·절로 읽었을 때만 성경 본문 플로팅 버튼을 보여야 한다
- FR-2: 사용자가 플로팅 버튼을 누르면 시스템은 바텀시트에 그 묵상 범위(시작 장:절 ~ 끝 장:절)의 개역개정 구절을 절 번호와 함께 보여야 한다
- FR-3: 시스템은 구절을 대한성서공회 온라인 성경(`https://www.bskorea.or.kr/bible/korbibReadpage.php?version=GAE&book=<책 코드>&chap=<장>`)에서 받아와야 한다
- FR-4: 본문 제목의 책 이름(예: `잠언`, `요한복음`, `에스겔`)을 대한성서공회 책 코드(예: `pro`, `jhn`)로 바꿀 수 있어야 한다. 성경 66권 전부
- FR-5: 본문이 두 장에 걸치면 두 장을 받아 범위에 맞게 이어 붙여야 한다
- FR-6: 받아오지 못하거나 받은 페이지에서 범위의 절을 찾지 못하면 바텀시트 안에만 "인터넷 연결을 확인해 주세요" 를 보여야 한다
- FR-7: 책 이름을 책 코드로 바꾸지 못하면 본문을 장·절로 못 읽은 경우와 같이 플로팅 버튼을 보이지 않아야 한다

## 5. 하지 않는 것
- 개역한글·새번역 등 다른 번역 — 묵상 글이 개역개정을 인용한다 (2026-11-26 대조: 잠언 23장 2곳·요한복음 5장 6곳 일치)
- 성경 전체를 앱에 넣어 오프라인으로 보기 (A안) — 묵상 글도 네트워크가 있어야 보이므로 얻는 것이 적다 (2026-11-26 진성 B안 선택)
- 장 전체 보기·범위 밖 절 보기 — 범위 절만 (2026-11-26 진성 결정)
- 바텀시트 안 "다시 시도" 버튼 — 안내만 (2026-11-26 진성 결정)
- 성경 단어 검색·책갈피·형광펜
- 메인 화면 변경
- 다른 사람에게 배포 — 개역개정은 대한성서공회 저작물이고 이용 허락을 받지 않았다. 개인 기기에서만 쓴다는 전제로 고른 번역이다 (허락 필요 여부는 법적으로 확인하지 않음)

## 6. 화면·사용 흐름
- 묵상 화면: 글이 보임 + 하단 캡슐(F-5·F-7·F-8) + 성경 플로팅 버튼
- 버튼 탭 → 바텀시트: 본문 제목 → (불러오는 중) → 절 번호 + 구절 목록
- 실패: 바텀시트 안 "인터넷 연결을 확인해 주세요"
- 닫기: 아래로 내리기 또는 바깥 탭 → 묵상 화면 그대로

## 7. 기술적 고려
- 대한성서공회 페이지는 HTML 이다. 한 장이 약 26KB (2026-11-26 curl 실측: 잠언 23장 26,359바이트, HTTP 200)
- 구절은 `<span class="number">절번호&nbsp;&nbsp;&nbsp;</span>구절</font></span><br />` 꼴로 한 줄씩 있다 (실측, `version=GAE&book=pro&chap=23`). 같은 페이지에 성경 단어 검색 등 다른 영역이 있다
- 구절 안에 `<font size='1'>사사로운</font>` (작은 글씨)·`<font class="orgin">스올</font>` 같은 태그가 섞여 있다 (실측). 작은 글씨는 원문에 없는 보충어 표시로 보인다 (추정)
- 교회 홈페이지·유튜브에 이어 세 번째 외부 의존이다. 대한성서공회가 페이지 구조를 바꾸면 성경 본문만 깨진다
- 본문 제목 형식은 `<책> <장>:<절>-<절>` 또는 `<책> <장>:<절>-<장>:<절>` 을 이미 읽는다 (코드 확인 `DevotionTitleParser.swift` `passagePattern`). 줄임 표기(`고린도전` 등)는 아직 처리하지 않는다 (2026-11-20 확정 결정)
- 실제 응답 HTML 을 fixture 로 저장해 테스트에 쓴다 (기존 `MorningDevotionTests/Fixtures/` 방식)

## 8. 성공 지표
- `xcodebuild test` 통과 (`.sap/config` 의 `TEST_CMDS`)
- fixture 기준: `잠언 23:24-35` → 12절, 첫 절 24·끝 절 35 / `요한복음 5:30-47` → 18절, 5:31 에 "증언하면"
- 실기기(무선 설치): 구약·신약 묵상 각각 버튼 → 바텀시트에 범위 절이 보이고, 비행기 모드에서는 바텀시트 안에만 안내가 보인다

## 9. 결정 필요
- 플로팅 버튼은 하단 캡슐 오른쪽 위(화면 오른쪽 아래)에 둔다? — 아니오면 다른 위치를 정한다 (캡슐이 화면 하단 가운데에 있어 겹치지 않는 곳이어야 한다)
- 구절은 버튼을 누를 때 받아온다(묵상 화면을 열 때 미리 받지 않는다)? — 아니오면 묵상 화면을 열 때 함께 받고, 그 실패가 묵상 화면 표시를 늦추거나 막지 않아야 한다
- 작은 글씨 보충어(`<font size='1'>`)는 다른 글자와 같은 크기로 보인다? — 아니오면 작게 보이게 한다
- 바텀시트는 처음에 화면 절반 높이로 열리고 끌어 올리면 전체 높이가 된다? — 아니오면 처음부터 전체 높이로 연다
- 같은 묵상에서 바텀시트를 다시 열면 다시 받지 않고 처음 받은 구절을 보인다? — 아니오면 열 때마다 받는다
