# PRD: morning-devotion

작성일: 2026-11-20

## 1. 개요
하루에 두 번 100주년기념교회의 지난 새벽 묵상 영상과 글을 본다. 아침에는 구약 묵상, 점심에는 신약 묵상이다.
교회 홈페이지에 하루 하나씩 올라온 지난 묵상(예: 2009-11-25 마태복음 1:1-25)을 순서대로 이어서 읽는다.
지금은 매번 다음 묵상의 글은 구글에서, 영상은 유튜브에서 따로 찾아야 해서 번거롭다.
앱을 열면 어제 본 묵상을 기준으로 다음 구약·신약 묵상의 영상과 글을 바로 보여주는 개인용 아이폰 앱을 만든다.

## 2. 목표
- 앱을 열면 검색하지 않고 다음에 볼 구약 묵상과 신약 묵상이 영상과 글로 나온다
- 앱이 구약·신약 각각 어디까지 봤는지 기억한다
- 이미 본 묵상을 앱 안에서 다시 찾아볼 수 있다

## 3. 대상 사용자
- 진성 1명. 매일 아침에 구약, 점심에 신약 묵상을 하나씩 본다
- 지금은 영상과 글을 매번 따로 찾는다
  - 글: 구글 검색으로 교회 홈페이지의 묵상 글을 연다 (예: `https://100church.org/home/board.php?board=cast&config=6&page=394&category=6&command=body&no=4714&body_only=y&button_view=n`)
  - 영상: 유튜브에서 "마태복음 1:1 100주년"처럼 **성경 본문 + 100주년**으로 검색해 나오는 영상을 본다
- 다음 묵상을 고르는 방법: 어제 읽은 본문의 장·절을 기억해 두고, 같은 성경 책에서 그 바로 다음 장·절을 검색해 연다. 검색에 안 나오면 교회 홈페이지에 들어가 찾는다
  - 예: 어제 요한복음 5:19-29 → 오늘은 요한복음 5:30부터 시작하는 묵상
- 구약과 신약은 서로 다른 해의 묵상 묶음을 따로 읽는다. 신약은 2020년 묶음을 따라간다. 2020년 글을 찾지 못한 날에만 2015년 글을 대신 읽었다. 2026-11-20 기준 진행 위치:

  | 구분 | 묵상 시간 | 따라가는 묶음 | 마지막으로 본 본문 | 다음 묵상 (홈페이지 조회 결과) |
  |---|---|---|---|---|
  | 구약 | 아침 | 2025년 | 2025/09/10(수) 잠언 23:12-23 | 2025/09/11(목) 잠언 23:24-35 |
  | 신약 | 점심 | 2020년 | 요한복음 5:19-29 (2020년 묶음에서는 2020/07/11, 유튜브 영상 제목 기준) | 2020/07/13(월) 요한복음 5:30-47 |

## 5. 하지 않는 것
- 다른 사람 배포(TestFlight·App Store): 사용자가 진성 1명이고, 배포하면 교회 콘텐츠 재배포 허락과 심사 문제가 생긴다
- 묵상 시각 알림: 1차 범위로 고르지 않았다
- 그날 새로 올라온 묵상 보기: 진성은 지난 묵상을 순서대로 읽는다
- 콘텐츠 직접 제작·편집: 교회가 올린 영상과 글을 보여주기만 한다

## 6. 제약
- 기술: SwiftUI(애플 공식 네이티브 UI 프레임워크). 진성의 학습 대상이다
- 설치: 진성의 아이폰 한 대에 Xcode로 직접 설치한다
- 외부 의존: 영상은 유튜브, 글은 교회 공식 홈페이지에 있다. 두 곳의 구조가 바뀌면 앱이 영향을 받는다
- 묵상 글은 첫머리에 날짜와 본문이 정해진 형식으로 적혀 있다 (진성이 보낸 화면 기준):
  ```
  2009년 11월 25일 (수)
  <본문> 마태복음 1:1-25/218장(새286) '주 예수님 내 맘에 오사'
  ```
  `/` 앞이 성경 본문이고, 뒤는 찬송가 번호와 제목이다
- 영상과 글을 이어 주는 열쇠는 날짜가 아니라 **성경 본문**(예: 마태복음 1:1)이다. 진성이 영상을 본문으로 검색하기 때문이다
- 2026-11-20 curl로 위 글과 목록을 요청하면 HTTP 200으로 내용이 온다 (기본 curl, 아이폰 Safari User-Agent 둘 다). 앞서 본 403은 웹 수집 도구 쪽 문제였다

## 7. 성공 지표
- 앱이 추천한 다음 묵상이 진성이 직접 고를 다음 묵상과 같은지 (구약·신약 각각)
- 앱이 보여준 영상의 본문과 글의 `<본문>` 줄이 일치하는지
- 앱을 쓰는 동안 묵상을 위해 유튜브·구글을 검색한 횟수 (목표 0회, 측정 기간은 결정 필요)

- 성공 지표 "검색 0회"를 며칠 동안 잴까? — 정하지 않으면 지표가 끝나지 않는다
