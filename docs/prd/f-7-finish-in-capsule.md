# PRD: F-7 "다 봤어요"를 이전·다음 캡슐로 옮기기

작성일: 2026-11-24 · 프로젝트 PRD: [00-project.md](00-project.md) · 관련: [f-5-glass-nav-swipe.md](f-5-glass-nav-swipe.md)

## 1. 개요
지금 묵상 화면의 "다 봤어요" 버튼은 본문(설교 글) 맨 끝에 있어서, 누르려면 끝까지 스크롤해야 한다.
진성은 영상만 보고 본문을 스크롤하지 않은 채 바로 "다 봤어요"를 누르고 싶다.
이 기능은
1. "다 봤어요"를 화면 하단 글래스 캡슐(F-5의 `‹ · ›`)의 가운데, 지금 점(●)이 있는 자리로 옮기고
2. 스크롤 없이도 누를 수 있게 된 만큼, 누르면 확인 창을 먼저 띄워 실수로 진행 위치가 넘어가는 것을 막는다

진행 위치는 "다 봤어요"로만 앞으로 가고 되돌릴 수 없다 (F-4 FR-5, 5장 "진행 위치를 사용자가 직접 앞뒤로 옮기기" 제외). 그래서 확인 창이 유일한 실수 방지 장치다.

## 2. 목표
- 묵상 화면을 열자마자 스크롤 없이 "다 봤어요"를 누를 수 있다
- "다 봤어요"를 한 번 잘못 눌러도 진행 위치가 바뀌지 않는다

## 3. 사용자 스토리

### US-1: 캡슐 가운데의 "다 봤어요"
**설명:** 진성으로서, 영상을 다 본 뒤 스크롤하지 않고 화면 아래 캡슐에서 "다 봤어요"를 누르고 싶다. 본문을 끝까지 내리지 않는 날도 있기 때문이다.
**수용 기준:**
- [ ] 안 읽은 글의 묵상 화면이 열리면, 스크롤하지 않은 상태에서 하단 캡슐이 `‹  다 봤어요  ›` 로 보인다
- [ ] 캡슐 안 "다 봤어요"는 배경 없는 글자 버튼(강조색)이다. 캡슐의 글래스 위에 다른 글래스 버튼을 겹치지 않는다
- [ ] 본문 맨 끝에는 "다 봤어요" 버튼이 없다
- [ ] 읽은 글("읽음" 표시가 있는 글)의 묵상 화면에서는 캡슐 가운데가 지금처럼 점(●)이다
- [ ] 이동 검색 중에는 캡슐 가운데가 지금처럼 불러오는 중 표시이고, "다 봤어요"는 보이지 않는다
- [ ] 글을 불러오는 중이거나 네트워크 오류 화면에서는 캡슐 가운데가 점(●)이다
- [ ] 안 읽은 글에서 `‹`·`›` 나 스와이프로 읽은 글로 넘어가면 가운데가 점으로, 읽은 글에서 안 읽은 글로 넘어가면 "다 봤어요"로 바뀐다

### US-2: 누르면 확인 창
**설명:** 진성으로서, "다 봤어요"를 잘못 눌러도 진행 위치가 넘어가지 않으면 좋겠다. 이제 스크롤 없이 바로 눌리는 자리에 있기 때문이다.
**수용 기준:**
- [ ] 캡슐의 "다 봤어요"를 누르면 진행 위치는 그대로이고, 화면 아래쪽에 액션 시트(confirmationDialog)가 뜬다
- [ ] 액션 시트에는 짧은 확인 문구와 "다 봤어요"·"취소" 두 선택지가 있다. 문구에 글의 날짜·본문은 넣지 않는다
- [ ] 액션 시트에서 "다 봤어요"를 고르면 지금 "다 봤어요"와 같은 결과가 나온다 (그 구분의 진행 위치가 이 글 날짜로 바뀌고 메인으로 돌아간다)
- [ ] "취소"를 고르거나 액션 시트 밖을 누르면 액션 시트만 닫히고, 묵상 화면·진행 위치·메인 줄은 그대로다

## 4. 기능 요구사항
- FR-1: 묵상 화면 하단 캡슐 가운데는 다음 순서로 하나만 보여야 한다 — 이동 검색 중이면 불러오는 중 표시, 그렇지 않고 글이 보이는 상태에서 "다 봤어요"를 보일 조건(F-4 FR-5: 안 읽은 글)이면 "다 봤어요" 버튼, 나머지는 점(●)
- FR-2: 본문 끝의 "다 봤어요" 버튼은 없어야 한다
- FR-3: 사용자가 캡슐의 "다 봤어요"를 누르면 시스템은 진행 위치를 바꾸지 않고 확인 액션 시트를 띄워야 한다
- FR-4: 사용자가 확인 액션 시트에서 "다 봤어요"를 고를 때에만 시스템은 지금의 "다 봤어요" 동작(진행 위치 저장, 메인으로 돌아가기)을 해야 한다. 그 동작의 규칙은 새로 만들지 않는다
- FR-5: 캡슐의 "다 봤어요"는 `‹`·`›` 와 같은 조건(이동 검색 중)에서 잠겨야 한다
- FR-6: 캡슐의 "다 봤어요"는 누를 수 있는 높이가 `‹`·`›` 와 같은 44pt 이상이어야 한다
- FR-7: 캡슐의 "다 봤어요"에는 VoiceOver 라벨 "다 봤어요"가 있어야 한다

## 5. 하지 않는 것
- 끝까지 스크롤해야 버튼이 나타나게 하는 조건 — 진성은 스크롤 없이 누르고 싶다 (2026-11-24)
- 누른 뒤 되돌리기(취소 토스트) — 진행 위치가 뒤로 가야 해서 F-4 FR-5와 부딪힌다
- 메인 화면 카드의 변경
- "다 봤어요" 이후 동작(진행 위치 규칙, 메인 복귀, 메인 줄 갱신) 변경

## 6. 화면·사용 흐름
- 안 읽은 글: 하단 캡슐 `‹  다 봤어요  ›` → "다 봤어요" 탭 → 아래쪽 액션 시트 [짧은 확인 문구 / 다 봤어요 / 취소] → "다 봤어요" → 메인 (그 줄이 다음 글)
- 읽은 글: 하단 캡슐 `‹ · ›` (지금과 같음)
- 이동 중: 하단 캡슐 `‹ (불러오는 중) ›` (지금과 같음)
- 재사용: F-5의 하단 글래스 캡슐, 지금 "다 봤어요" 동작

## 7. 기술적 고려
- F-5 US-2 기준 "캡슐이 '다 봤어요' 버튼과 겹쳐 둘 중 하나를 누를 수 없게 되지 않는다"는 이 기능 뒤로 의미가 없어진다 (같은 캡슐 안으로 들어감)
- 캡슐 가운데 자리는 지금 점 크기에 맞춘 고정 너비다. "다 봤어요"가 들어가면 캡슐이 넓어져야 한다
- 확인 액션 시트가 떠 있는 동안에도 이동 검색이 끝나 글이 바뀌는 경우는 없다 (이동 검색 중에는 "다 봤어요"가 잠겨 있음, FR-5)
- 버튼 모양·액션 시트는 단위 테스트로 판정하기 어렵다. 판정할 수 있는 것은 "확인 전에는 진행 위치가 그대로인가"다. 모양은 시뮬레이터 스크린숏으로 확인한다
